# 面评台 · Interview Desk

> 一个**在线共享的面试评分与录用决策工具**，专为高校社团招新、活动面试这类 1–5 位评委的小型面试而生。
> 扫码即面、多设备实时同步、拖拽即决策、AI 只做统计归纳——最终录用由人拍板。

![单文件前端](https://img.shields.io/badge/前端-单文件-blue) ![零依赖](https://img.shields.io/badge/后端-Node.js%20零依赖-green) ![License](https://img.shields.io/badge/license-MIT-yellow)

## ✨ 核心功能

- **在线共享面试间**：主持人创建面试并生成加入码/二维码，评委用昵称 + 加入码即可进入，多台设备实时同步。
- **自定义评分维度与权重**：维度不预设，由面试官自行添加、分配权重（新维度按 100 均分，可手改；总和不强制为 100，按加权平均计算）。
- **打分 + 备注**：每个维度 0–10 分即时保存，可写亮点/顾虑/原话，另有不计分的「其他备注」。
- **决策台**：候选人以热力色卡片呈现（越红越靠前），拖进「录取/部门篓」＝录用、拖进「淘汰篓」＝淘汰，四处视图（面试间/决策台/排行/报告）状态同步。
- **对比台**：拖入 2–4 位候选人并排展开，横向对比各维度得分与简历。
- **Word 简历**：拖拽上传 .docx，全屏查看、缩放、打分左右分屏。
- **汇总排行**：可按综合分或单/多因素平均分切换排序。
- **AI 报告**：用可编辑的提示词让 AI 读取本场评分数据，产出结构化录用建议（AI 只归纳，不替你做决定）。
- **导出与迁移**：报告支持 PDF / Word / Excel / Markdown；原始数据导出 Excel；含简历的完整备份 JSON 用于换机继续。

## 🧱 技术栈

- 后端：**纯 Node.js 内置模块**（`http` / `crypto` / `fs`），零第三方依赖。
- 前端：**单文件 SPA**（内联 HTML / CSS / JS），无框架。
- 实时：轮询 + 变更检测 + 输入焦点保护（避免打断移动端键盘/滑杆）。
- 简历解析、导出、二维码等均通过 CDN 按需加载第三方库。

## 🚀 快速开始

```bash
# 克隆后，无需 npm install（后端零依赖）
node server.js
# 默认监听 8081，浏览器打开 http://localhost:8081
# 可用环境变量 PORT / HOST 覆盖端口与地址
```

## 📁 目录结构

```
interview-desk/
├── server.js            # 零依赖 Node 服务（API + 静态托管）
├── public/
│   └── index.html       # 单文件前端（全部 UI 与逻辑）
├── package.json
└── data.snapshot.json   # 运行时数据快照（已在 .gitignore 中，不会提交）
```

## 🔒 数据与隐私

- 面试数据保存在**服务端内存**，并尽力落盘到 `data.snapshot.json`；**服务重启或重新部署会清空内存数据**，请用「导出 → 完整备份」自行留存。
- AI 配置（含 API Key）绑定到对应面试、保存在服务端，**不会下发给客户端**；`data.snapshot.json` 已在 `.gitignore` 中，请勿手动提交，以免泄露真实候选人数据与密钥。
